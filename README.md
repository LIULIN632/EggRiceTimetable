# 蛋炒饭课程表 (EggRice Timetable)

极简清新的 Android 课程表 App，支持**真实教务系统一键导入**，所有数据仅存本地。

## 特性

- **课程表周视图** — 7天 × 节次网格，单双周切换，卡片展示课程/教师/教室
- **教务系统导入** — 支持正方、强智、青果、超星四大教务系统，内置 290+ 所学校，可自定义添加学校
- **多渠道导入** — Excel (.xlsx/.xls)、HTML、JSON 备份、分享码
- **多课表管理** — 创建/切换多个课表方案
- **个性化主题** — 5套配色（海盐蓝/抹茶绿/樱花粉/紫藤紫/蛋炒饭）+ 深色/浅色模式
- **课程自定义** — 格子高度、圆角、透明度、边框样式可调
- **上课提醒** — 通知提醒
- **成绩查询** — 正方教务在线查成绩（总评/平时/期末/期中），支持按学期切换
- **修课情况查询** — 已修课程、学分要求与绩点统计（正方 v9 学业情况）
- **成绩存档** — 一键同步全部学期成绩保存到本地，离线可查看
- **导入提速** — 记住学校上次成功的接口组合，再次导入通常 1 次请求完成
- **百宝箱** — 学习资源 / 今天吃什么 / 任务清单 / 好物清单 / 留声树洞 / 老师查询

## 技术栈

Kotlin · Jetpack Compose · Material3 · Room (SQLite) · OkHttp · MVVM (StateFlow)

Android 10+ (API 29-34) · Gradle 8.14.3 · AGP 8.7.3

## 构建

```bash
# 开发测试
./gradlew assembleDebug

# 正式发布
./build.sh
```

或双击 `build.bat` 一键构建。

## 隐私

- 所有数据存储在本地 Room 数据库
- 无需网络权限（教务导入除外）
- 无广告、无追踪、无数据上传

## 许可

仅限个人学习使用。
